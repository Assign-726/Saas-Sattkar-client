Connecting a channel manager

  1. Create an API key for this channel under API keys with rooms:read, bookings:read and bookings:write.
  2. The channel reads prices, rooms left and restrictions from {{ rates_url }}?from=YYYY-MM-DD&to=YYYY-MM-DD.
  3. Subscribe its webhook to ari.changed under Webhooks so it re-reads the feed the moment a booking, rate or closure changes.
  4. It sends reservations to /api/v1/bookings (with your room code as external_room_id), and changes or cancellations to /modify and /cancel. See the developer guide.
