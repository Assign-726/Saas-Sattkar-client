Push an order (Zomato, Swiggy, website…)

Match items by menu_item_id, sku, short_code or exact name. If you leave out unit_price, the aggregator price is used when set, otherwise the menu price. Sending the same external_id again returns the original order with "duplicate": true, so retries are safe.

curl -X POST {{ api_base }}orders \
  -H "Authorization: Bearer hk_live_…" -H "Content-Type: application/json" \
  -d '{
    "external_id": "SWG-5567123",
    "order_type": "delivery",
    "customer": {"name": "Anita", "phone": "9876543210", "address": "12 MG Road"},
    "items": [
      {"sku": "BUT-4921", "quantity": 2},
      {"name": "Garlic Naan", "quantity": 4, "notes": "extra butter"}
    ],
    "payment": {"status": "paid"},
    "notes": "Ring the bell"
  }'

The order appears in this branch's POS and kitchen display as placed. If the key is tied to a channel, the order is tagged with it and the channel's commission is recorded for the profit & loss report.

Webhooks

We POST JSON to your URL when something happens. Answer with any 2xx within 8 seconds. Failed deliveries are retried after 1, 5, 30, 120 and 360 minutes; after 15 failures in a row the endpoint is turned off and shown in red here.

Verify every request. Compute an HMAC-SHA256 of timestamp + "." + raw body with your signing secret and compare it with v1 in X-Webhook-Signature: t=…,v1=…. Reject anything older than five minutes.

# Python
import hmac, hashlib, time
def verify(secret, header, body: bytes):
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > 300: return False
    mac = hmac.new(secret.encode(), parts["t"].encode() + b"." + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(mac, parts["v1"])

// Node.js
const crypto = require('crypto');
function verify(secret, header, rawBody) {
  const p = Object.fromEntries(header.split(',').map(s => s.split('=')));
  if (Math.abs(Date.now() / 1000 - Number(p.t)) > 300) return false;
  const mac = crypto.createHmac('sha256', secret).update(p.t + '.' + rawBody).digest('hex');
  return crypto.timingSafeEqual(Buffer.from(mac), Buffer.from(p.v1));
}

Errors and limits

Errors look like {"error": {"code": "unknown_items", "message": "…"}}. Codes: 401 unauthorized, 403 insufficient_scope, 404 not_found, 409 items_unavailable / sold_out / order_closed, 422 for invalid fields, 429 rate_limited. Each key may make 120 requests a minute; see the X-RateLimit-Remaining header.

Channel managers & OTAs

STAAH, SiteMinder, eZee and similar channel managers sync availability to Booking.com, Agoda, MakeMyTrip and Expedia. Give the channel manager a key from this property: it reads availability and pushes bookings, which block a room on the tape chart and appear in guest profiles and the P&L.
