availability Boolean Optional true (Available for order, default) or false (Out of stock / 86'd).

food_type String Optional Legal FSSAI food category: "veg" (Green Dot) "non_veg" (Brown Triangle) "egg" (Yellow Dot). Default is "veg". Aliases: type, diet, is_vegetarian.

is_vegan Boolean Optional true if 100% plant-based (no dairy, ghee, butter, paneer, honey). Note: Only valid for "veg" items; automatically reset to false for Non-Veg or Egg.
